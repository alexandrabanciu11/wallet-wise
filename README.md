# WalletWise

WalletWise is a personal finance website designed to help users manage their money, track their income and expenses, and plan their budgets.

## Features

- User registration and login
- Personal dashboard
- Income and expense tracking
- Transaction categories
- Monthly budgeting
- Currency support for GBP and RON
- English and Romanian language support
- Supabase authentication and database integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Supabase

## Purpose
The aim of WalletWise is to make personal finance easier to understand and help users become more aware of their spending habits, but also learn to track their progress financally.
